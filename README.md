# CINEVIX Works — House Production

Website resmi **CINEVIX**, rumah produksi visual yang berdedikasi menghadirkan karya sinematik berkualitas tinggi.

## Struktur Proyek

```
cinevix web/
├── index.html          # Entry point utama
├── assets/
│   ├── css/
│   │   └── style.css   # Design system & custom styles
│   ├── js/
│   │   └── main.js     # Interaktivitas & animasi
│   └── img/            # Aset gambar & video
└── README.md
```

## Teknologi

- HTML5 Semantik
- Vanilla CSS (CSS Variables, Flexbox, Grid)
- JavaScript ES6+
- [Swiper.js](https://swiperjs.com/) — Slider/Carousel
- [AOS](https://michaeloryl.github.io/animate-on-scroll/) — Animasi scroll
- [Font Awesome](https://fontawesome.com/) — Ikon
- [Google Fonts](https://fonts.google.com/) — Tipografi Sinematik (Bebas Neue, Outfit, Plus Jakarta Sans)

## Fitur Unggulan

- 🎬 **Cinematic Studio Aesthetic** (A24 / Legendary Inspired)
- 🎞️ **Analog Film Grain Overlay & Viewfinder Corners**
